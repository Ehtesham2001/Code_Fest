ASSIGNMENT 4 - CREATE A WEBPAGE USING BOOTSTRAP AND PUBLISH IT
Project: CodeFest 2026 - College Technology Festival

FILES
- index.html: webpage structure and Bootstrap components
- style.css: custom styling
- script.js: demo registration-form interaction
- assets/tech-illustration.svg: local scalable vector image

RUN LOCALLY
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html in Chrome/Firefox.
4. Keep internet access enabled: Bootstrap CSS and JS load from CDN.

BOOTSTRAP FEATURES USED
- Responsive navbar and collapsible mobile menu
- Container, row, 12-column grid, responsive columns
- Buttons, badges, cards, forms, responsive table
- Spacing, typography, background and utility classes
- Bootstrap JavaScript bundle

CUSTOMIZATION / IMAGE OPTIMIZATION
- style.css customizes Bootstrap's default appearance.
- Hero illustration is a local SVG vector asset; it scales cleanly and is lightweight.
- Update event name, dates, schedule, venue and contact details before publishing.
- Test mobile, tablet and desktop widths with Chrome DevTools.

PUBLISH WITH GITHUB PAGES
1. Sign in at https://github.com/ and create a PUBLIC repository, e.g. assignment-4-bootstrap.
2. Upload index.html, style.css, script.js and the assets folder to the repository root.
3. Open repository Settings -> Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for deployment. Copy the live URL shown in the Pages section.
7. It will generally look like https://YOUR-USERNAME.github.io/assignment-4-bootstrap/
8. Open the URL on desktop and mobile to verify it.

ALTERNATIVE: NETLIFY
1. Sign in at https://www.netlify.com/.
2. Choose Add new site / Deploy manually (label may vary).
3. Drag and drop the extracted project folder.
4. Open the generated public URL and test it.

IMPORTANT
The form is only a front-end demonstration; it does not store or email registrations.
A backend or form service is needed for real submissions.
Keep the same folder structure when uploading.
